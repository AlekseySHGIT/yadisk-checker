# Файлы на Яндекс Диске: что можно скачать

Простое веб-приложение для iPhone. Оно показывает, какие файлы на Яндекс Диске
доступны для скачивания, рисует круговую диаграмму и выводит список недоступных серверов.
Работает на Vercel или локально на компьютере.

## Как устроена проверка

1. Через API получаем список всех файлов (`GET /v1/disk/resources/files`).
2. Для каждого файла запрашиваем ссылку на скачивание (`GET /v1/disk/resources/download`).
3. Проходим по ссылке, включая редиректы (`downloader.disk.yandex.ru` → сервер хранилища),
   и просим у сервера только первый байт файла (`Range: bytes=0-0`).
4. Если сервер не ответил (отказ соединения, таймаут, DNS, HTTP 5xx), он попадает
   в список недоступных. **Все следующие файлы на этом сервере сразу помечаются
   как «не может быть скачан»**, без запросов к нему.
   Пока новый сервер проверяется первый раз, остальные файлы с него ждут результата.
5. HTTP 4xx считается ошибкой конкретного файла, а не сервера.

Проверкой управляет страница в браузере: по одному запросу `/api/check` на файл,
3 файла параллельно. Сервер ничего не хранит, OAuth-токен лежит в зашифрованной
HttpOnly-cookie.

> На Vercel доступность серверов проверяется из дата-центра Vercel (Франкфурт, `fra1`),
> а не из вашей сети. Если важна именно ваша сеть, запускайте локально.

## Деплой на Vercel

1. Импортируйте репозиторий: https://vercel.com/new. Framework Preset: **Other**,
   остальное по умолчанию (настройки уже в `vercel.json`).
2. В **Settings → Environment Variables** добавьте:
   - `YANDEX_CLIENT_ID`
   - `YANDEX_CLIENT_SECRET`
   - `COOKIE_SECRET`: любая длинная случайная строка (ключ шифрования cookie)

   После этого сделайте **Redeploy**.
3. В настройках приложения на https://oauth.yandex.ru добавьте Redirect URI
   `https://<ваш-проект>.vercel.app/api/callback`.
   Права: «Яндекс Диск REST API» → «Чтение всего Диска» (`cloud_api:disk.read`).
4. Откройте `https://<ваш-проект>.vercel.app` на iPhone и нажмите «Войти через Яндекс».
   Чтобы приложение было как отдельная иконка: «Поделиться» → «На экран „Домой“».

## Локальный запуск

Нужен Node.js 18 или новее. Сторонних библиотек нет.

1. Скопируйте `.env.example` в `.env` и заполните.
2. В настройках приложения на oauth.yandex.ru добавьте Redirect URI
   `http://localhost:3000/api/callback`.
3. Запустите `npm start` и откройте http://localhost:3000.

## Демо без аккаунта

```
npm run mock     # фальшивый Яндекс Диск с «упавшими» серверами
npm run demo     # во втором терминале
```
Откройте http://localhost:3000 и нажмите «Войти через Яндекс» (или токен `test-token`).

## Структура

- `public/index.html`: интерфейс и логика проверки
- `api/*.js`: функции Vercel (вход, список файлов, проверка файла, скачивание)
- `lib/`: общий код и проверка ссылки на скачивание
- `dev/local.js`: локальный сервер; `dev/mock-yandex.js`: имитация Яндекс Диска
